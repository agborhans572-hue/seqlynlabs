# PH Bio Labs website copy

Public page snapshot of https://phbiolabs.com/ captured October 6, 2026.

Run `node serve.mjs`, then open http://127.0.0.1:4173.

The original HTML, CSS, fonts, branding, and product imagery are retained. Larger assets load from their original public URLs to fit the computer's available disk space. Category filters and progressive product loading run locally.

Checkout, accounts, order tracking, newsletter signup, and form delivery require backend integration. Forms and purchase actions are disabled in this preview. The copy does not include the original WordPress database or private services.

`mirror-report.json` lists captured pages and download failures. `node mirror.mjs` refreshes the public snapshot; run `node finalize.mjs` afterward.
